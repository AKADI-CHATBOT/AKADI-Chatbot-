# REGLAS GENERALES INALTERABLES

1. Antes de cambiar algo en el repositorio se debe verificar.
Verificar significa: ver el archivo, ver el hash completo de 64, ver que existe en el repo publico, correr el validador. Si no se verifica, no se cambia.

2. Cada regla debe cumplirse realmente, no simulacion.
No basta con decir que se cumplio. Hay que mostrar el output real del validador, el hash real, el archivo real. Si es simulado, es BLOCKED.

3. Cada vez que se pide proponer, deben ser 5 propuestas reales, nada de simulacion, por peso escoger automaticamente la que tiene mas peso, no preguntar SE PUEDE.
Proponer significa: 5 opciones reales con peso, escoger la de mas peso y aplicarla. No preguntar si se puede, aplicar la de mas peso.
