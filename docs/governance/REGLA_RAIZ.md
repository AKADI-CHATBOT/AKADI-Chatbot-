# REGLA RAIZ - NO PROMESA SIN ARCHIVO

1. Ningun README puede declarar un numero, acta, imagen, o prueba, si no hay un archivo en el repo publico que lo respalde, visible para terceras personas.
2. Ningun acta puede decir ACTA FINAL SELLADA si no tiene hash completo de 64 caracteres para cada archivo que dice sellar.
3. Ningun acta de test puede decir ACTA FINAL SELLADA sin decir TEST por dentro del archivo, no solo en el nombre de la carpeta.
4. Ningun ledger puede decir que hay cadena si no tiene prev_hash y hash del evento, con hash completo.
5. Antes de publicar, HIL debe ver el archivo, ver el hash, y ver que el archivo esta en el repo publico. Si no esta, se dice EN PROGRESO, no se declara como hecho.
6. Si un dato no esta, se dice NO ENCONTRADO, no se inventa, no se deduce, no se cierra.
