# AGF-GCELL - Roles Publicos

Este archivo es la version publica limitada.
La regla interna completa esta en repo privado AKADI, no en este repo publico.

## Roles publicos
- SIL: codigo que ejecuta, sin juicio.
- HIL: humano que valida.
- Asistente: maquina que prepara y audita, no da PASS solo.

## No Dependency on Private Commercial LLM APIs
AGF-GCELL core runs locally, without any dependency on private commercial LLM chatbot APIs. Asistente / Asistente can be any LLM, but the core does not send biometric data to external APIs.
